# Contributing

1. Use fictional data only.
2. Never publish real company, target, seller, investor, employee, vendor, contract, budget, infrastructure, security, ERP, data, AI, incident, transaction, or diligence information.
3. Never commit credentials or private URLs.
4. Separate facts, assumptions, and hypotheses.
5. Findings should identify evidence and confidence.
6. Add validation cases for new scoring or diligence logic.
