# Diligence Test Cases

## Missing Evidence
Expected: mark evidence gap; do not infer control effectiveness.

## High Severity / Low Confidence
Expected: flag for validation before treating as confirmed.

## One-Time Cost Spike
Expected: normalize sustainable run-rate separately.

## Unsupported Critical Application
Expected: record operational and remediation impact.

## Vendor Concentration
Expected: assess dependency, exit options, and transaction impact.
