# Technology Due Diligence Request List

Typical requests:
- application inventory
- infrastructure inventory
- cloud accounts summary
- architecture diagrams
- network/security standards
- cybersecurity policies
- incident history summary
- backup/recovery evidence
- vendor/contract list
- software licenses
- IT budget and actuals
- org chart and role descriptions
- ERP landscape
- data/analytics architecture
- AI use-case inventory
- major project roadmap
- technical debt register
- audit reports
- business continuity / DR documentation
